## [0.1.0-phase1] - 2024-10-18

### Added

- Monorepo structure with `apps/backend`, `apps/frontend`, and `infra/docker` skeleton folders
- Root configuration files: `.gitignore`, `.gitattributes`, `.editorconfig`, `.env.example`
- MIT License
- Governance files: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`
- GitHub templates: bug report, feature request, and pull request templates
- Requirements documentation: vision & scope, functional requirements, non-functional requirements, user stories, roles & permissions matrix, glossary
- UML diagrams: use case, class, sequence (4 flows), activity, and state diagrams (all in Mermaid)
- Architecture documentation: architecture overview (C4 L1 & L2), deployment architecture, security design, coding standards
- Data model: ER diagram (10 entities) and full data dictionary
- REST API endpoint catalog (25+ endpoints)
- Architecture Decision Records: ADR-001 through ADR-006
- Documentation index (`docs/README.md`)
- Project README with roadmap and architecture overview

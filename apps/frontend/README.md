# Frontend — Next.js Application

This directory will contain the Next.js 14 (App Router) frontend application (Phase 4 onwards).
It provides a responsive, TypeScript-typed UI for all CloudOps Manager modules — dashboard, servers, projects, applications, and alerts — with real API integration via TanStack Query.
Authentication flows, loading/error states, and role-gated views are handled client-side with server-side rendering where appropriate.
